## Cómo se usa

- **La versión viva es el artifact de claude.ai.** Ahí se guardan los cambios para todo el equipo.
  Para que otros editen, hay que compartirlo con nivel Colaborador o Editor.
- **Los HTML de esta carpeta son una copia del código.** Si los abrís sueltos no traen el
  contenido, porque los datos viven en el artifact.
- **Los JSON de `datos/` son el contenido inicial.** Para recuperarlo, usá "Importar" en la página.
  Si el equipo ya editó, exportá el JSON actual desde la página y reemplazá el respaldo.
